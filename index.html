How to use it, and what the result means

Getting a dump

In Betaflight Configurator open the CLI tab, type diff all, press Enter and copy everything it prints. Do it for both quads, or for one quad before and after a firmware update or a tune. Use diff all, not plain diff: the plain one skips the profiles you are not currently on, so PIDs, filters and rates go missing. INAV is the same, and its control, mixer and battery profiles get their own sections.

Reading the result

  • changed: the setting is in both dumps with different values. The last column is the numeric step from A to B.
  • only A / only B: a dump only lists what differs from the firmware defaults, so a setting missing on one side means that side runs the default.
  • Settings are matched by name and by profile or rate profile, so line order does not matter. feature, beeper and blackbox lines show up as on or off.
  • Across firmware versions you will see extra changes, because defaults move between releases.

The generated CLI

It sets everything that differs to the target value, switches into the right profile or rateprofile first, and ends with save. Features and beepers that only the source has are switched back off. A plain set that only the source has cannot be reset, because the default is not in the dump, so it ends up as a comment for you to handle. Read it through before pasting it into the CLI tab, and keep a backup dump.

Privacy

Parsing happens in your browser. The share link stores both dumps compressed inside the URL hash, which browsers never send to a server, so anyone with the link sees your dumps. Strip anything you do not want to share first (name, GPS home, VTX tables).
